## 1. 计算机账户与 AD

- 计算机加入域后，会自动创建**计算机账户**。
- 计算机账户也有**密码**，为了计算机与 DC 之间的通信，它**每 30 天**自动更改一次。
- 计算机与 DC 根据这个密码信息建立**安全通道（Secure Channel）** 进行通信。
- 如果计算机**超过 30 天**难以与 DC 通信，就要让它使用 VPN 或 DirectAccess，或者在组策略中延长计算机账户密码的**最长使用期限**。

---

## 2. AD 账户管理技巧

- **组策略的应用位置**：组策略可以链接到 OU（组织单位），但不能单独链接到账户默认创建所在的 **Users** 或 **Computers 容器**。
- **更改默认位置**：如果想让账户默认创建在 OU 中，可以使用 **`redirusr`**（用户）和 **`redircmp`**（计算机）命令。
- **批量操作工具（LDIFDE）**：需要把部门、电话号码等用户属性**批量导入** AD，或者反过来**导出** AD 数据时，使用 **`LDIFDE`**。

```cmd
redirusr "OU=NewUsers,DC=korea,DC=com"
redircmp "OU=NewComputers,DC=korea,DC=com"
```

## 3. AD 复制

### 有多台 DC 时

- 有多台 DC 时，为了让所有 DC 的数据保持一致，会**持续进行复制**。
- **多主机方式**：可以在多台 DC 中的**任意一台**上同时修改数据。
- **复制的核心目标**：准确性、完整性、一致性以及快速的性能。

### 复制的技术特点

| 特点 | 内容 |
| --- | --- |
| 按属性复制 | 从 Windows Server 2003 开始，复制单位变为**属性**，即使是同一个对象，只要修改的是不同属性，就能无冲突地合并。 |
| 按分区复制 | AD 数据库不是整体复制，而是**按分区**复制。（架构、配置、域、GC、应用程序） |
| 自动拓扑 | **AD 会自动设计** DC 之间如何复制效率最高。 |

## 4. 站点和服务

AD 默认认为所有 DC 都在**高速网络**中并据此进行复制。但如果公司网络被**慢速 WAN 链路**分隔，复制和身份验证就可能出现问题。

**站点（Site）** 是对网络结构进行分组的概念，用于在慢速网络环境中控制 AD 复制，并引导用户使用**最近（最快）网络上的 DC**。

![Sites and replication](../images/ad-sites-replication.svg)

### 站点的功能与组成

| 项目 | 内容 |
| --- | --- |
| 复制控制 | 调整站点之间（WAN）复制的时间和频率，减轻线路负担。 |
| 服务本地化 | 让客户端使用**本站点内的 DC** 进行身份验证。 |
| 站点划分 | 以高速连接的网络（子网）为单位划分站点。 |
| 站点链接 | 连接站点与站点的复制路径。 |
| 开销 | 为每个站点链接设置开销（Cost），优先使用开销低的路径。 |

## 5. RODC

### 什么是 RODC？

- 普通 DC 可以对数据进行**读和写**，而 **RODC（Read-Only Domain Controller）** 顾名思义，是只以**只读**方式工作的 DC。
- 它部署在**物理安全薄弱的地点**（如分支机构），即使 DC 被盗，也能防止重要信息外泄。

![RODC at a branch office](../images/ad-rodc.svg)

### RODC 的安全强化功能

- **不保存密码**：RODC 默认不保存与安全相关的重要信息（密码）。
- **指定缓存**：为了提升性能，可以指定只缓存（保存）**特定用户**的密码。这样既能加快该地点用户的身份验证，又能保持安全。

## 总结

- 加入域后会创建**计算机账户**，其密码**每 30 天**更改一次，并用于与 DC 建立**安全通道**。
- **Users/Computers 容器**不能链接 GPO，所以要用 `redirusr`、`redircmp` 把默认位置改为 OU。批量操作使用 **LDIFDE**。
- AD 复制是**多主机**、**按属性**（从 2003 起）、**按分区**的复制，拓扑由 AD **自动**建立。
- **站点**控制慢速 WAN 链路上的复制，并让客户端使用**附近的 DC**。站点之间用**站点链接**和**开销**连接。
- **RODC** 是面向安全薄弱地点的**只读 DC**，默认不保存密码，**只缓存指定的用户**。
